# 📊 ETF 포트폴리오 리밸런싱 계산기

> 올웨더·마돈나 포트폴리오를 정해진 비중으로 관리하기 위한 개인용 리밸런싱 도구

🔗 **[앱 바로가기](https://salt99.github.io/jhw_investPort/)**

---

## ✨ 주요 기능

### 포트폴리오 관리
- 여러 포트폴리오를 **탭**으로 독립 관리 (연금저축, DC연금 등)
- 포트폴리오 추가 / 삭제 / 순서 변경
- **템플릿** 기반 포트폴리오 생성 (올웨더형, 마돈나형, 직접 구성)
- 기존 포트폴리오 복사하여 새 탭 생성

### 리밸런싱 계산
- 총 평가액(추가금 포함) 입력 → **매수/매도 수량 자동 산출**
- 알고리즘: `목표수량 = int(총평가액 × 목표비중 / 현재가)`, 나머지는 예수금
- 종목별 현재 비중 → 목표 비중 진행 바 시각화
- 거래 후 **예수금(총평가액 포함)** 자동 계산

### ETF 종가 자동 조회
- GitHub Actions가 **평일 오후 4시 30분**에 네이버 금융에서 종가 수집
- `prices.json` 자동 업데이트
- 앱에서 **↓ 종가 로드** 버튼 한 번으로 전체 현재가 반영

### 입력 편의
- 수량: **슬라이더 드래그** 또는 **직접 탭하여 입력**
- 현재가: 탭하여 직접 수정
- **↩ 되돌리기 / ↪ 다시복원** (최대 30단계 undo/redo)

### 이력 관리
- 매수/매도 가이드 저장
- 리밸런싱 완료 시 자동 저장
- 날짜별 이력 불러오기 / 삭제
- 불러오기 시 현재가·수량·총평가액 입력 폼에 자동 반영

### 리밸런싱 완료
- 완료 버튼 클릭 → 변경 내용 미리보기 후 확인
- 보유수량 자동 업데이트 + 이력 저장

## 🔧 기술 구조

```
jhw_investPort/
├── index.html          # 앱 전체 (단일 파일)
├── fetch_prices.py     # ETF 종가 수집 스크립트 (네이버 금융)
├── prices.json         # 최신 종가 데이터 (Actions가 자동 업데이트)
└── .github/
    └── workflows/
        └── fetch_prices.yml  # 평일 16:30 자동 실행
```

- **프론트엔드**: 순수 HTML/CSS/JS (프레임워크 없음)
- **데이터 저장**: 브라우저 `localStorage` (개인 기기에만 저장)
- **종가 수집**: GitHub Actions + Python (네이버 금융 JSON API)
- **호스팅**: GitHub Pages (무료)

## 🔒 개인정보

- `index.html`에는 개인 금융정보(수량·가격·평가액)가 포함되지 않습니다
- 모든 데이터는 **본인 기기의 localStorage에만 저장**됩니다
- GitHub에는 종목 구성·비중 정보만 포함됩니다

## ⚙️ 종가 자동 수집 수동 실행

Actions 탭 → **Fetch ETF Prices** → **Run workflow**

장 마감 전이거나 당일 데이터가 필요할 때 수동으로 즉시 실행할 수 있습니다.
